## ทรัพย์ทดสอบแผนที่

| ฟิลด์ | ค่า |
|--------|-----|
| รหัสทรัพย์ | `WP-0060` |
| URL ทดสอบ Google Maps | ลิงก์จุด 19°49'20.6"N 99°50'37.8"E (เชียงใหม่) |

พิกัดที่คาดหวังหลังแยกจากลิงก์: `19.8224, 99.843845`

## รันทดสอบอัตโนมัติ

```bash
npm run test:site:setup
npm run test:map:wp0060          # E2E แอดมิน (ต้อง login ได้)
node scripts/test-map-wp0060-db.mjs  # บันทึกพิกัดผ่าน DB โดยตรง
node scripts/lookup-property.mjs WP-0060
```

ตัวแปรเสริม (ถ้าต้องการ override):

```bash
BASE_URL=http://localhost:3000 \
TEST_EMAIL=tester@gmail.com \
TEST_PASSWORD=123456789 \
TEST_PROPERTY_CODE=WP-0060 \
node scripts/test-property-map-wp0060.mjs
```

## ขั้นตอนทดสอบด้วยมือ

1. เข้า `/admin/login` ด้วยบัญชีด้านบน
2. เปิดแก้ไขทรัพย์ `WP-0060`
3. วางลิงก์ Google Maps ในช่อง「ตำแหน่งบนแผนที่」→ กด「บันทึกตำแหน่ง」
4. ต้องเห็นข้อความสีเขียว「บันทึกตำแหน่งสำเร็จ」และแผนที่ตัวอย่าง
5. กด「บันทึก」ฟอร์มทรัพย์ → ต้องเห็น「บันทึกข้อมูลสำเร็จ」
6. เปิดหน้าสาธารณะทรัพย์ → ต้องมีแผนที่ด้านล่าง

## หมายเหตุปัญหาที่พบ

- ลิงก์ Google Maps ที่ให้มา **แยกพิกัดได้ปกติ** (`19.8224, 99.843845`)
- ก่อนหน้านี้ WP-0060 มีสถานะเสีย: `latitude=null` แต่ `longitude=99.843845` ทำให้แผนที่ไม่แสดง
- ปุ่ม「บันทึกตำแหน่ง」เคยไม่แสดงผลสำเร็จ/ล้มเหลว (แก้แล้ว — แสดงข้อความสีเขียว/แดง)
- หลังกด「บันทึกตำแหน่ง」ต้องกด「บันทึกข้อมูล」ฟอร์มอีกครั้งเพื่อเก็บลง DB
